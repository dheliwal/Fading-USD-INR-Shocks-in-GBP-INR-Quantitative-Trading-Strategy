# Fading-USD-INR-Shocks-in-GBP-INR-Quantitative-Trading-Strategy
Python-based FX research testing short-term mean reversion in GBP/INR after significant USD/INR shocks. Includes historical data collection, volatility-based event detection, contrarian backtesting, parameter optimisation, transaction cost analysis, and out-of-sample evaluation using pandas, NumPy and yfinance.
